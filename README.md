# 에이전트 지식 연구 랩 LMS

코딩 경험이 없는 참여자가 각자 다른 에이전트를 바이브코딩으로 만드는 10회 과정의 정적 학습 사이트입니다.

## 파일

- `index.html`: 웹사이트 구조와 스타일
- `lessons.js`: 10회차 수업 내용
- `app.js`: 화면, 기획 노트, 리서치 노트, 진도 및 백업 기능

## GitHub Pages 배포

1. GitHub 저장소를 새로 만들고 위 세 파일을 저장소의 최상위 폴더에 업로드합니다.
2. 저장소의 **Settings → Pages → Build and deployment**에서 **Deploy from a branch**를 선택합니다.
3. 파일을 올린 브랜치(예: `main`)와 폴더 `/ (root)`를 선택하고 저장합니다.
4. GitHub Pages 화면에 표시되는 사이트 URL이 준비될 때까지 기다립니다.

GitHub Pages 사이트는 공개될 수 있습니다. 개인 정보, API 키, 사내 자료를 파일에 넣지 마세요. 브라우저에 입력한 기록은 사이트 운영자에게 제출되지 않고 각 기기의 브라우저에만 남습니다. 브라우저 데이터를 지우거나 기기를 변경하기 전에 기록을 JSON 파일로 내보내세요.

## 실행

`index.html`을 브라우저에서 열면 학습 콘텐츠를 볼 수 있습니다. 로컬 파일이나 비보안 환경에서는 브라우저 정책에 따라 복사 또는 저장 기능이 제한될 수 있습니다. GitHub Pages의 HTTPS 환경 사용을 권장합니다.
